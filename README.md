# Calculadora de IMC

Primeira aplicação web desenvolvida com React e JavaScript para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

## Tecnologias utilizadas

- **React 19** — construção da interface.
- **JavaScript** — lógica e funcionalidades.
- **Vite 8** — ambiente de desenvolvimento.
- **CSS** — estilização da aplicação.
- **Oxlint** — análise estática do código.

## Funcionalidades

- Inserção de peso e altura.
- Cálculo automático do IMC.
- Exibição do resultado e classificação correspondente.
- Validação dos campos de entrada.
- Interface simples e intuitiva.
